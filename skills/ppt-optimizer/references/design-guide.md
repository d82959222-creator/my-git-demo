## 字号体系

### 黄金比例（1.618）

```
封面标题 (44-56pt) × 0.618 ≈ 章节标题 (28-36pt)
章节标题 × 0.618 ≈ 正文 (16-22pt)
正文 × 0.618 ≈ 注释 (10-14pt)
```

### 投影距离与最小字号

| 投影距离 | 最小可读字号 |
|----------|-------------|
| 3 米 | 18pt |
| 5 米 | 24pt |
| 8 米 | 32pt |
| 10 米 | 40pt |

> 工地/现场环境投影 → 建议最小 20pt

## 布局原则

### 三分法

将幻灯片水平和垂直各分三等份，关键元素放在交叉点上：
```
┌──────┬──────┬──────┐
│      │  ✦   │      │
│      │      │      │
├──────┼──────┼──────┤
│      │      │      │
│  ✦   │  ★   │  ✦   │  ★ = 最佳焦点
│      │      │      │
├──────┼──────┼──────┤
│      │      │      │
│      │  ✦   │      │
└──────┴──────┴──────┘
```

### 留白规则

- 幻灯片四周留白 ≥ 0.5 inch (1.27 cm)
- 标题区约占顶部 15-20%
- 正文区约占 60-70%
- 页脚区约占底部 5-10%

### 内容密度

```
每页幻灯片：
- 标题：1 个（必选）
- 要点：3-5 个（推荐）
- 表格：≤ 6 列 × 8 行
- 图片：1-2 张
- 每要点字数：10-25 字（标题式）/ 30-80 字（说明式）
```

## 视觉层次

### 四层结构

```
第一层: 标题 (36-44pt, Bold, 主色)     ← 最先看到
第二层: 副标题 (22-28pt, Bold, 深灰)    ← 第二眼
第三层: 正文 (14-18pt, Regular, 深灰)   ← 阅读区
第四层: 注释/页脚 (9-10pt, 浅色)        ← 辅助信息
```

### 创建层次感的技巧

1. **大小对比** — 标题至少是正文的 2 倍
2. **颜色对比** — 重要内容用主色，次要用灰色
3. **粗细对比** — Bold 标题 + Regular 正文
4. **空间对比** — 标题后留 2 倍行距
5. **图标辅助** — 用图标引导视线

## 内容写作原则

### 标题
- ≤ 15 个字
- 包含关键词
- 用动词引导（"实现…"、"构建…"、"分析…"）

### 要点
- 每页 3-5 个要点
- 每条 1-2 行为佳
- 用数据说话（"提升 30%"而非"大幅提升"）
- 并列结构（都是名词短语，或都是动宾结构）

### 禁则
- ❌ 整段复制粘贴
- ❌ 一页超过 8 个要点
- ❌ 字号小于 11pt
- ❌ 超过 3 种字体
- ❌ 超过 4 种颜色（不含黑白灰）
- ❌ 截图带水印/时间戳

## 图片使用

- 分辨率 ≥ 1920×1080
- 保持原始比例，不拉伸
- 图片加 1px 细边框（`#CCCCCC`）
- 图表自带的数据标签字号 ≥ 10pt

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 字体太小 | 后排看不清 | ≥ 14pt 正文 |
| 文字太多 | 无人阅读 | 精简到 3-5 要点 |
| 配色刺眼 | 视觉疲劳 | 降低饱和度 |
| 无视觉层次 | 抓不住重点 | 用大小/颜色区分 |
| 图片模糊 | 显得不专业 | 使用高清图 |
| 表格太密 | 数据不可读 | 控制列数 ≤ 6 |
| 动画过多 | 分散注意力 | 简约过渡 |
| 字体不统一 | 显得业余 | 通篇 ≤ 2 种字体 |
